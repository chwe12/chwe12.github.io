用claude把工作以來的筆記整理得清楚一點，然後放到anytype上。試著把claude和anytype連線，看起來效果不錯。<br />
首先需要claude和anytype的桌面版、Node.js，我之前就有下載所以沒有特別遇到問題。<br />
在anytype setting > API中創新的API給claude，然後開啟claude setting > Developer > Edit Config，找到`claude_desktop_config.json`，先備份一個相同的檔案以免有問題。<br />
把claude關閉，檢查工作管理員內是否有claude背景程式，如果有也要關掉。加入以下程式碼，把`YOUR_NEW_API_KEY`換成剛剛儲存的anytype API:<br />
```
{
  "mcpServers": {
    "anytype": {
      "command": "npx",
      "args": [
        "-y",
        "@anyproto/anytype-mcp"
      ],
      "env": {
        "OPENAPI_MCP_HEADERS": "{\"Authorization\":\"Bearer YOUR_NEW_API_KEY\",\"Anytype-Version\":\"2025-11-08\"}"
      }
    }
  }
}
```
<br />
打開claude並看連接器是否有anytype。<br />
測試後可以正常讀寫anytype的內容，未來可能需要加上"未經確認，不刪除筆記、不覆寫整篇內容、不進行批次修改。"，以免哪次忘記不小心把整份筆記毀了。<br />
還沒有買claude前想了好多方法和各種app都不能輸出想要的筆記形式，不是太簡略就是內容的格式有問題...果然還是要花錢解決問題啊。<br />
未來終於可以用AI完美的使用我的第二大腦了。
