IoT 考題紀錄​

2025/11 考試，紀錄不清楚、忘記寫甚麼的問題，把選擇錯誤選項改成寫正確選項

  • 在物聯網系統中，選擇使用Redis 作為資料存儲時，下列哪一項特性「最」能滿足高頻率讀寫的需求？
    • 以記憶體為基礎的存儲方式，提供高速讀寫能力
  • 為了高效處理需要即時回應的任務並減輕雲端負擔，下列哪一項邊緣運算的設計策略「最」能提升系統的穩定性和可靠性？
    • 邊緣設備中部署分散式協同處理機制以提高容錯性
    • 將邊緣設備的資料處理優化為只存儲資料之詮釋資料（Metadata）
      錯誤：Metadata 是描述資料本身屬性、結構、來源、時間等資訊的附加資料。不是資料本體。
  • 若要利用Raspberry Pi 讀取一個類比感測器（例如：可變電阻）的數值，下列哪一項是最常見且標準的做法？
    • 外接一個類比數位轉換（Analog-to-Digital Converter, ADC）的積體電路，將感測器的類比訊號轉換成數位資料後，再透過I2C（Inter-Integrated Circuit）或SPI（Serial Peripheral Interface）介面傳輸給Raspberry Pi
  • JSON 格式
    • JSON Object 內的Value 可以是字串、數值、JSON Object 或JSON Array
    • JSON Object 最外層是大括弧，其中資料的格式為Key/Value Pair，Key 與Value 之間以冒號(:)隔開，多個Key/Value Pair 間用逗號隔開
    • JSON Object 可以有巢狀結構，即JSON Object 內可以含有JSON Object，也可以含有JSON Array
  • 在設計物聯網設備時，為了確保 UART （Universal Asynchronous Receiver-Transmitter）通訊的穩定性，下列哪種方法「最」為有效？
    • 使用硬體流量控制（請求發送RTS/清除發送CTS）避免數據丟失
  • AQMP 通訊協定架構
    • Producer (生產者、或者說訊息發送者)、Exchange (交換器、透過交換器解偶生產者與消費者的關聯)、Queue (佇列、訊息的存放區域)、Consumer (消費者、或者說訊息接收者)、Channel (通道、生產者與消費者的傳輸管道)、Connection (連線)
  • 霧運算IoT 系統出現決策延遲的最可能原因，下列哪一項正確？
    • 邊緣節點負載過重缺乏平衡
    • 可參考：https://medium.com/it-digital-%E4%BA%92%E8%81%AF%E7%B6%B2/%E9%9B%B2%E8%A8%88%E7%AE%97%E4%B9%8B%E4%B8%8A%E9%82%84%E6%9C%89%E9%9C%A7%E8%A8%88%E7%AE%97-%E9%9C%A7%E8%A8%88%E7%AE%97%E7%9A%84%E5%85%A5%E9%96%80-fog-computing-3eab52996c71
  • 智慧手環與手機藍牙連接後頻繁斷線，應如何故障排除？
    • 測試手環的電池電量是否過低
  • LiDAR（Light Detection and Ranging）感測技術通常使用下列哪一種波長範圍的雷射光來測量距離？
    • 近紅外光
  • ISO 14443 為非接觸式RFID 定義了兩種卡的類型：Type A和Type B。
    • 信號調變（modulation）、編碼（encoding）不相同
    • 悠遊卡、一卡通皆為ISO 14443 應用
    • 感測距離皆為為0~10 公分
  • 下列哪一項 5G 應用情境符合需要部署大量感測器的物聯網應用？
    • mMTC（Massive Machine Type Communication）
  • 5G 技術中的超可靠低延遲通訊（Ultra-Reliable and Low Latency Communications, URLLC）主要應用於哪一類情境？
    • 工業自動化和遠距醫療
  • 在ZigBee 網路層中，下列哪一個特性「最」能幫助網路在節點故障時自動恢復其拓撲結構？
    • 鄰居表（Neighbor Table）的動態更新
  • NB-IoT 的技術特性
    • NB-IoT 不支援VoLTE
    • NB-IoT 不支援基地台間的交遞（Handover）
    • NB-IoT 涵蓋範圍較LTE 廣
  • 根據FCC 公布的47 CFR part 15 規定，操作RF 射頻設備和人體之間至少需間隔多少的距離？
    • 8 英吋
  • 在使用 MU-MIMO （Multi-User Multiple-Input Multiple-Output）技術的無線網路中，下列哪一種情況「最」有助於發揮MU-MIMO 的優勢來提高多用戶的網路效能？
    • 讓多個用戶分佈在不同的空間位置上
  • 智慧交通資料收集平台需要儲存來自交通攝影機的原始影像、空氣品質感測器的結構化數據以及社群媒體的非結構化文字。下列哪一種數據儲存方案最適合作為這些多樣化原始數據的集中存放區？
    • 雲端資料湖（Cloud Data Lake）
  • 在智慧城市平台中，要安全地管理數以百萬計、無使用者介面的物聯網裝置（如智慧電錶）的身分，並授權存取雲端 API，下列哪一種身分驗證機制最合適？
    • 基於X.509 的驗證
  • 在 EPCglobal 網路架構中，使用實體標記語言（Physical Markup Language, PML）的主要目的，下列哪一項正確？
    • 描述EPC 標籤的物件屬性和狀態
