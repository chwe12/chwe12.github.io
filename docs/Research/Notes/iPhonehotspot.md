# iPhone hotspot problem
*最後更新時間：2022/02/28*<br />

iPhone選擇只使用USB熱點的時候常常接上手機卻連不到，一開始我的解法是先把手機拔掉，用工作管理員關掉所有iTune軟體，然而還是有連不到的情況。

## 步驟
### 試錯
目前嘗試不能每次都穩定連上的方式：
1. 重插拔手機
2. 重開關USB熱點選項
3. 重置所有網路設定
4. 重開電腦+1.2.3點
5. 拔掉手機USB線並將iTune相關軟體關閉，再重新接上

### 解法
後來發現以下的方法，目前還可以百百成功接上USB熱點。
1. 接上手機之後打開裝置管理員，右鍵移除第一個裝置驅動：
![CK](/img/doc/iphone/ip0.png)<br />

2. 跳出下面這個畫面的時候，不要把刪除驅動程式軟體打勾：
![CK](/img/doc/iphone/ip1.png)<br />
3. 當跳出重開機畫面的時候，不要重開機，直接在插拔手機一次，接下來就連的到USB熱點了。
<br />
最後，iPhone手機名稱最好和預設不一樣。
