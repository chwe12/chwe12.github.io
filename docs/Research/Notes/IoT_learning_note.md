## RFID 與 NFC

### NFC
- 幾乎是 RFID 的第二代
- 頻率 13.56MHz
- 感應距離最小
- 雙向傳輸，可交換資料

### RFID 依照頻率分類
| 頻率 | 範例 | 特性 | 距離 | 標準 | 讀取 |
|:-----:|:----:|:----:|:-----:|:-----:|:-----:|
| LF (125k/135k) | 生物晶片、汽車鑰匙 | 穿透水金屬 | 近距離 | | 感應耦合 |
| HF (13.56M) | 悠遊卡、行動支付 | 安全高 | 5–10 cm | ISO14443 A/B | 感應耦合 |
| UHF (922M) | ETag、物流 | 穿不過水金屬 | 2–10 m | ISO18000-63/6C | 回波散射 |

- 低頻適用生物標籤
- 新資料可附加在舊資料，或是完全複寫標籤資料
- UHF RFID 可大範圍讀取、同時讀取許多標籤，標籤可重複使用
- ISO 14443 Type A / Type B：調變與編碼不同，悠遊卡、一卡通皆為此應用，感測距離 0~10 公分

### RFID 記憶體區
- Reserved（kill / Access 密碼）
- EPC（最重要資料）
- TID（唯讀、防盜）
- USER

### 碰撞問題
- 多個標籤同時傳資料會碰撞
- ALOHA（UHF 使用）調整傳送時間

## 網路層技術

| 技術 | 頻率 | 支援/架構 | 傳輸方式 | 特點 | 規範/組織 |
| :-----: | :-----: | :-----: | :-----: | :-----: | :-----: |
| ZigBee | 台灣：2.4G/2.45G、歐洲：915M、868M | Mesh、IEEE 802.15.4 | 短距無線傳輸 | 低功耗、中低速率 (20k~250)、16～26 個頻道 | IEEE 802.15.4、ZigBee |
| Thread | 2.4G (與ZigBee相同) | 6LoWPAN、固定 IP | 短距離無線傳輸 | 低功耗、高安全性 | IEEE 802.15.4 |
| Bluetooth / BLE | 2.4 GHz | Mesh Network、支援 BLE（4.0/5）| 廣播、網路、配對 | 低功耗、短封包、長距離、支援 iBeacon | Bluetooth SIG |
| Wi-Fi | 2.4G / 5G / 6G | 無線網路傳輸 | Wi-Fi 6(ax)：高速、Wi-Fi 7(be)：更快 | | IEEE 802.11 |
| UWB | 超寬頻（多頻段）| 裝置對裝置 | 短脈衝（ToF）| 超精準定位、高安全、短距離、低功耗、成本較高 | |
| 5G | 高頻（mmWave）| 蜂巢式網路 | 定向天線傳輸 | 高頻、抗干擾、定向傳輸、覆蓋小需多基地台 | |

- ZigBee 節點故障時，靠鄰居表（Neighbor Table）的動態更新自動恢復拓撲
- NB-IoT：不支援 VoLTE、不支援基地台間交遞（Handover）、涵蓋範圍較 LTE 廣
- 5G 應用情境：大量感測器 → mMTC；工業自動化、遠距醫療 → URLLC
- MU-MIMO：多個用戶分佈在不同空間位置時最能發揮效能

## 定位技術

| 場景 | 技術 |
|:-----:|:----:|
| 室外 | GPS |
| 室內 | 藍牙、ZigBee、UWB(最精準)、Wi-Fi |

RTLS 定位方式：
- TDOA：訊號衰減
- TOA：多讀取器衰減
- AOA/AOD：角度
- RTT：往返時間

## 雲端、資料與協定

- Redis：以記憶體為基礎的存儲，提供高速讀寫
- 雲端資料湖（Cloud Data Lake）：適合集中存放影像、結構化、非結構化等多樣原始資料
- 邊緣運算：部署分散式協同處理機制提高容錯性
- 霧運算決策延遲：最可能是邊緣節點負載過重缺乏平衡（[參考](https://medium.com/it-digital-%E4%BA%92%E8%81%AF%E7%B6%B2/%E9%9B%B2%E8%A8%88%E7%AE%97%E4%B9%8B%E4%B8%8A%E9%82%84%E6%9C%89%E9%9C%A7%E8%A8%88%E7%AE%97-%E9%9C%A7%E8%A8%88%E7%AE%97%E7%9A%84%E5%85%A5%E9%96%80-fog-computing-3eab52996c71)）
- Metadata：描述資料本身屬性、結構、來源、時間等資訊的附加資料，不是資料本體
- 大量無介面裝置（如智慧電錶）的身分驗證：基於 X.509 的驗證
- JSON：最外層是大括弧，Key/Value 以冒號隔開、多組以逗號隔開；Value 可以是字串、數值、Object 或 Array，可巢狀
- AMQP 架構：Producer、Exchange、Queue、Consumer、Channel、Connection

## 硬體與介面

- Raspberry Pi 讀類比感測器：外接 ADC，再透過 I2C 或 SPI 傳給 Pi
- UART 穩定性：使用硬體流量控制（RTS/CTS）避免數據丟失
- LiDAR 通常使用近紅外光
- 智慧手環藍牙頻繁斷線：先檢查電池電量是否過低

## 電磁波與 SAR

| 類型 | 例子 | 管理單位 |
| :-----: | :-----: | :-----: |
| 游離 | X光、αβγ 射線 | 原子能委員會 |
| 非游離 | 紫外線、紅外線、可見光、無線電、微波爐 | 環保署 |

- 手機 SAR：2 W/kg
- 基地台最高：500W（1W=30dBm）
- NCC：負責檢測無線設備頻段
- 跳頻可降低干擾
- FCC 47 CFR part 15：RF 設備與人體至少間隔 8 英吋
